# Плагіни SystemOn

Програма підвантажує файли `*.py` з **двох** каталогів (у такому порядку; один і той самий **ім’я модуля** завантажується лише з першого знайденого файлу):

1. **`%USERPROFILE%\systemonplugins`** (або `~/systemonplugins`) — ваші плагіни; мають пріоритет над прикладами з репозиторію.
2. **`systemonplugins/`** поруч із `systemon.py` — приклади та тести в проєкті.

У кожному файлі плагіна має бути функція **`register_plugin(app_context)`**. У словнику `app_context` є ключ **`"main_window"`** — екземпляр головного вікна `SystemOn` (PyQt5).

- Файли, що починаються з **`_`**, ігноруються (наприклад, `__init__.py` не підходить для автозавантаження як плагін — краще не класти туди пакети).
- Помилки імпорту/реєстрації пишуться в консоль (якщо вона є).

Приклад мінімального плагіна: **`example_smoke_test.py`**.
