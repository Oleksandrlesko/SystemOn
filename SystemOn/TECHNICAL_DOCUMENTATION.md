# Технічна документація проекту SystemOn

## Опис проекту

**SystemOn** — це десктопний монітор системних ресурсів для операційної системи Windows. Програма надає користувачам у реальному часі інформацію про використання процесора, оперативної пам'яті, дискового простору, запущені процеси та апаратні сенсори GPU/RAM. Додаток має графічний інтерфейс користувача з візуалізацією даних у вигляді графіків, дерева процесів та інформаційних карток.

### Основні функції:
- Моніторинг використання CPU (загальне та по кожному ядру окремо)
- Моніторинг використання оперативної пам'яті
- Моніторинг використання дискового простору для всіх доступних дисків
- Відображення запущених процесів у вигляді дерева (батьківські/дочірні)
- Візуалізація даних у реальному часі через графіки
- Управління процесами (запуск, завершення, freeze/unfreeze)
- Моніторинг сенсорів у вкладці `Sensors` (GPU/RAM)
- Відображення системної інформації
- Підтримка плагінів для розширення функціональності
- Налаштування стилів через CSS

## Бібліотеки та залежності

### Файл `requirements.txt`

У репозиторії задані **мінімальні версії** зовнішніх пакетів (верхніх меж немає — оновлення підтягує `pip` з урахуванням сумісності):

| Пакет   | Обмеження в файлі | Примітка |
|---------|-------------------|----------|
| **PyQt5** | `>=5.15.0`        | Qt5 / PyQt5 5.15 — базова лінія для стабільних збірок |
| **psutil** | `>=5.9.0`      | Моніторинг процесів, CPU, RAM, дисків |

Встановлення: `pip install -r requirements.txt`

Опційно для вкладки **Sensors** (GPU): на ПК має бути доступна утиліта **`nvidia-smi`** (драйвер NVIDIA); до `requirements.txt` вона не входить.

### Основні бібліотеки (з requirements.txt):

1. **PyQt5**
   - Версія: згідно з `requirements.txt` (мінімум 5.15; новіші патчі через `pip install -U`)
   - Призначення: Створення графічного інтерфейсу користувача (GUI)
   - Використання:
     - `QApplication` — головний клас додатку
     - `QMainWindow` — головне вікно програми
     - `QWidget`, `QVBoxLayout`, `QHBoxLayout`, `QGridLayout` — компоненти інтерфейсу та розмітка
     - `QStackedWidget` — перемикання екранів (Overview, Processes, Performance, Drives, Sensors)
     - `QScrollArea` — прокрутка списку процесів
     - `QThread`, `pyqtSignal` — багатопотоковість для оновлення даних
     - `QDialog` — діалогові вікна
     - `QTextBrowser` — текст системної інформації (`systeminfo`)
     - `QComboBox` — вибір швидкості оновлення графіків
     - `QProgressBar` — індикатори прогресу для дисків
     - `QLabel`, `QPushButton`, `QCheckBox`, `QFrame` — картки та керування
     - `QPainter`, `QPixmap` — малювання графіків (компонент `RGraph`)
     - `QIcon`, `QFont`, `QPalette`, `QColorDialog` — іконки, шрифти, тема

2. **psutil**
   - Версія: згідно з `requirements.txt` (мінімум 5.9)
   - Призначення: Отримання інформації про системні ресурси та процеси
   - Використання:
     - `psutil.process_iter()` — ітерація по процесам
     - `psutil.cpu_percent()` — використання процесора
     - `psutil.cpu_count()` — кількість ядер процесора
     - `psutil.virtual_memory()` — інформація про оперативну пам'ять
     - `psutil.disk_partitions()` — список розділів дисків
     - `psutil.disk_usage()` — використання дискового простору
     - `psutil.Process()` — управління окремими процесами

### Стандартні модулі Python:

- **sys** — системні параметри та функції
- **os** — робота з операційною системою (файли, шляхи)
- **math** — математичні операції (для розрахунку оптимальної сітки графіків)
- **time**, **json** — часові мітки та збереження налаштувань
- **tempfile**, **shutil** — тимчасові файли та очищення
- **ctypes** — виклики WinAPI (`GetVolumeInformationW`, `GetOEMCP` / `GetACP` тощо)
- **subprocess** — запуск системних команд (`systeminfo`, `nvidia-smi`, `wmic`)
- **importlib.util** — динамічне завантаження модулів (плагіни)

### Основні класи та компоненти:

#### 1. **SystemOn (QMainWindow)**
   - Головний клас програми
   - Ініціалізує інтерфейс користувача
   - Керує відображенням даних
   - Обробляє події користувача

#### 2. **ProcessFetcher (QThread)**
   - Окремий потік для збору системної інформації
   - Оновлює дані про процеси, CPU, пам'ять, диски та сенсори
   - Використовує сигнали PyQt5 для передачі даних у головний потік
   - Забезпечує плавне оновлення інтерфейсу без блокування

#### 3. **RGraph (QLabel)**
   - Кастомний компонент для відображення графіків
   - Малює графіки використання ресурсів у реальному часі
   - Підтримує налаштування кольорів через hue_offset
   - Автоматично адаптується до розміру вікна

#### 4. **SystemInfoDialog (QDialog)**
   - Діалогове вікно для відображення системної інформації
   - Спочатку виконується `cmd /c "chcp 65001 >nul && systeminfo"` (вивід часто в UTF-8), за відсутності успіху — звичайний `systeminfo`; далі `_decode_systeminfo_output()` обирає кодування за оцінкою якості тексту (кирилиця, ключові рядки, штраф за типове «кракозябри»)
   - Успадковує стильову таблицю головного вікна, якщо передано `parent`

#### 5. **StartProcessDialog (QDialog)**
   - Діалогове вікно для запуску нових процесів
   - Дозволяє користувачу ввести команду для виконання

### Допоміжні функції:

- **load_icon()** — завантаження іконок з підтримкою PyInstaller/Nuitka
- **plugin_search_directories()**, **load_plugins()** — каталоги пошуку та динамічне завантаження плагінів (`~/systemonplugins`, `systemonplugins/` поруч із `systemon.py`, опційно `sys._MEIPASS/systemonplugins` у зібраному onefile)
- **loadStyle()** — завантаження CSS стилів (спочатку з папки користувача, потім за замовчуванням)
- **memory_string()** — форматування розміру пам'яті
- **optimal_grid()** — розрахунок оптимальної сітки для відображення графіків CPU
- **read_gpu_metrics()** — отримання метрик GPU через `nvidia-smi`
- **read_memory_frequency()** — частота RAM через `wmic`
- **read_memory_details()** — деталізовані метрики RAM (used/available)
- **_decode_systeminfo_output()**, **_score_systeminfo_decoded()**, **_run_systeminfo_bytes()**, **_windows_console_codepages()** — запуск і декодування `systeminfo` (UTF-8 / OEM / ACP / UTF-16)
- **_get_volume_label_win32()**, **drive_card_title()** — мітка тома та заголовок картки диска у форматі «Назва тому (C:)» на Windows (`GetVolumeInformationW`)

## Технічні особливості

### Багатопотоковість:
- Використовується `QThread` для збору даних у фоновому режимі
- Сигнали PyQt5 (`pyqtSignal`) забезпечують безпечну передачу даних між потоками
- Інтерфейс завжди залишається відзивчивим

### Оновлення даних:
- Процеси оновлюються в реальному часі
- CPU та пам'ять оновлюються кожні 0.5 секунди
- Графіки зберігають останні 60 точок даних
- Сенсори GPU/RAM оновлюються в тому ж фоновому циклі `QThread`

### Візуалізація:
- Графіки малюються за допомогою `QPainter` та `QPixmap`
- Підтримується антиаліасинг для плавних ліній
- Кольори адаптуються до теми інтерфейсу через HSL
- Режими **Overall** / **Cores** / **Threads**: графіки CPU мають ту саму **фіксовану висоту**, що й графік пам’яті (`graph_height`), розтягуються **на всю ширину** контенту; у сітці **рівномірний `columnStretch`**, мінімальна висота рядка відповідає висоті графіка

### Плагіни:
- Динамічне завантаження з **двох** місць (у порядку пошуку; **однакове ім’я модуля** — лише перший файл):
  1. **`~/systemonplugins`** (`%USERPROFILE%\systemonplugins` на Windows) — особисті плагіни користувача
  2. **`systemonplugins/`** у каталозі з `systemon.py` — приклади з репозиторію (у т.ч. `example_smoke_test.py`)
- У зібраному **onefile**-додатку додатково перевіряється `sys._MEIPASS/systemonplugins`, якщо папку включено в збірку
- Файли `*.py`, ім’я яких починається з **`_`**, пропускаються
- Плагіни повинні містити функцію **`register_plugin(app_context)`**; у контексті є **`main_window`**

### Стилізація:
- Використовується Qt Stylesheets (CSS-подібний синтаксис)
- Підтримка користувацьких стилів через файл `~/rmstyle.css`
- Темна тема за замовчуванням
- Для `QComboBox` (наприклад, «Update speed») задано фон і контраст списку `QAbstractItemView` у зведеній таблиці стилів головного вікна та базовому `style.css`, щоб пункти меню залишались читабельними у світлій і темній темах

### Кросплатформенність:
- Програма орієнтована на Windows (використовує `os.startfile()`, `systeminfo`)
- Може бути адаптована для інших платформ через psutil

## Інтерфейс користувача

### Головне вікно:
- **Верхня панель**: Відображення поточного використання CPU, Memory та Disk у відсотках
- **Вкладки**:
  - **Processes**: Дерево процесів (parent/child)
  - **Graphs**: Графіки використання CPU (по кожному ядру) та пам'яті
  - **Drives**: Інформація про всі диски з індикаторами заповненості
  - **Sensors**: Картки сенсорів GPU/RAM (температура/споживання GPU, частота та обсяг RAM)

### Меню:
- **File**:
  - Start a Process — запуск нового процесу
  - Exit — вихід з програми
- **Options**:
  - Always on Top — вікно завжди поверх інших
  - View System Information — відображення системної інформації

### Контекстне меню процесів:
- Expand Selected — розгорнути вибрані гілки дерева
- Collapse Selected — згорнути вибрані гілки дерева
- Freeze — призупинити вибрані процеси (`psutil.Process.suspend()`)
- Unfreeze — відновити вибрані процеси (`psutil.Process.resume()`)
- Force Terminate — примусове завершення вибраного процесу

## Формати даних

### Процеси:
- Process ID (PID)
- Назва програми
- Кількість потоків
- Користувач
- Використання пам'яті (MB)
- Використання CPU (%)
- Стан процесу (Running/Frozen)

### Сенсори:
- GPU Temperature
- GPU Power Usage
- Memory Frequency
- Memory Used
- Memory Available
- Sensor Source (статус доступності джерела метрик)

### Диски:
- Заголовок картки: **мітка тому Windows та літера** у форматі `Назва (C:)` (якщо мітки немає — `Local Disk (C:)`)
- Облік використання через `psutil.disk_usage(mountpoint)`
- Використано/Загальний обсяг (з автоматичним форматуванням: B, KB, MB, GB, TB...)
- Відсоток заповненості
- Візуальний індикатор прогресу

## Розширення функціональності

### Створення плагінів:
1. Створіть файл Python (наприклад `my_plugin.py`) у **`~/systemonplugins`** або скопіюйте приклад з **`systemonplugins/`** у проєкті
2. Реалізуйте функцію **`register_plugin(app_context)`**
3. Використовуйте **`app_context["main_window"]`** для доступу до головного вікна (`SystemOn`)
4. Додавайте віджети, дії меню тощо через API PyQt5 (у поточній версії головне вікно не реєструє «слоти» плагінів — розширення повністю на стороні плагіна)

Детальніше — у **`systemonplugins/README.md`** у репозиторії.

### Налаштування стилів:
1. Створіть файл `~/rmstyle.css`
2. Використовуйте Qt Stylesheets синтаксис
3. Перезапустіть програму для застосування змін
